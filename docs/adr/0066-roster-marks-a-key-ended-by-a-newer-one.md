# The roster marks a key ended by a newer one beside the student status

A newer redeem ends the oldest Classroom API Key when a student already holds two. The teacher asked to see that, and the notice is already 已在其他電腦兌換. The class roster is one row per student, and its status column already says 有效 or 停用. The notice goes in that same cell, beside the student status, and stays until the ended key's own expiry. The key is not shown. A second column, or one row per key, would turn the seat list into a key list. The 有效 Key table is the operator's key dump and is not this roster.
