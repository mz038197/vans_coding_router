# A student holds at most two live Classroom API Keys per sitting

Redeeming issues a new Classroom API Key. One student may hold two live keys for one Class Session. Issuing a third ends the oldest. The classroom computer and the home computer can both keep working. Session Seat Limit still counts that student once.

## Considered Options

- **One live key**: rejected. Redeeming at home would end the key still on the classroom computer.
- **No cap**: rejected. A copied key would keep working until the sitting ends or the teacher disables the student, and a later redeem would not end it.
