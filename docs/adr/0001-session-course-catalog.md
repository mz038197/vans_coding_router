# Class Session carries Course Catalog YAML

Teachers need a per-sitting install list for the classroom extension without students placing `classroom-installs.yaml`. We store a Course Catalog (YAML, same shape as the extension sample) on each Class Session, defaulting new sessions to `actions: []`. Students fetch it with a dedicated extension GET authorized by Classroom API Key (not only embedded in redeem), including after the session ends (last saved version). `pegasi_router` must keep the same API shape and behavior so `classroom-one-click-install` can target either router via `routerBaseUrl`. This router does not host first-class file-asset downloads; catalog actions remain command-oriented for the extension to run. Portal authoring is no longer a YAML textarea; see ADR 0003.
