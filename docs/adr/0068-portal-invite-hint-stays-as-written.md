# The Portal invite hint stays as written

Under the Invite Code, Portal keeps「若遺失 API Key，可再次輸入同一邀請碼取回（課堂未過期前）」. Redeeming the same Invite Code again with the same identity returns that student's key for the sitting.

## Considered Options

- **Rewrite the hint to explain how keys are issued**: rejected. The sentence students already see stays, and it is accurate.
