# Closing asks once, and reopening does not ask again

關閉課堂 asks the teacher to confirm with「確定要關閉此課堂嗎？關閉後學生的金鑰會暫停，畫面仍會顯示原來的到期時間。重新開啟後，還沒到期的金鑰可以繼續用，不用重新兌換。」 重新開啟 then takes effect immediately. It does not open the expiry editor and it does not ask a second time. The earlier dialog said the keys die at once and that reopening means setting a future expiry. That described ending the sitting, not closing it.

## Considered Options

- **Ask again before 重新開啟**: rejected. The button already names the action, and reopening does not choose a new expiry.
